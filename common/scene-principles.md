## 🏛️ 诉讼/仲裁场景

**原则 L01 — 法院/仲裁委强制要求，不审必要性**
官方/法院/仲裁委强制要求的资质（诉讼材料、仲裁材料），不审"为什么必须"、不追问"是否有替代方案"。法律规定的必须提交，无可替代空间。
- 不套合作类规则：R02（双章合同）、R07（转授权）对诉讼/仲裁场景不适用。
- 仅确认：有无对应官方文书附件（如劳动仲裁申请书、法院材料清单）。
- 豁免范围精确说明：
  - 豁免阶段二：业务必要性（Q1/Q2）和主体必要性（法律强制已明确，无需申请人额外说明）
  - 仍须确认：看流向（资质流向对应法院/仲裁委）、看用途（用途=诉讼/维权/仲裁）
  - 阶段三：替代控制豁免；R02（双章合同）、R07（转授权）、C01证据链层级检查一并豁免
  - 若资质类型为品牌/商标授权书，C01证据链层级检查也豁免，仅确认该授权书是法院指定的举证材料即可
  - 确定性工具输出：L01场景下 R11（截图必填）和 R05（法人资质须有截图/合同）的 SUPPLEMENT 标记自动豁免，法院通知/仲裁材料本身即为证据
- 佐证：GS001（仲裁），GS002（打假起诉），GS009（商标侵权起诉）

**原则 L02 — 区分资质接收方 vs 事由中出现的平台名**
诉讼事由中会出现涉案平台（如拼多多、抖音），不要将其误解为"给该平台使用"。
- 正确读法：资质流向方=法院；事由中的平台名=案件发生的场景平台。
- 易犯错误：看到"拼多多"就判"平台场景"，实际是在拼多多上起诉侵权店铺。
- 佐证：GS002

**原则 L03 — 商标类诉讼直接通过条件**
商标侵权类起诉（未授权挂链/销售仿品/侵权行为）：
1. 有明确侵权事实（未授权擅自使用/销售）
2. 注册号已提供（R01 不触发）
3. 起诉意图明确（维权行为，不追问必要性）
→ 满足以上三点，应通过，不再追问。
- 佐证：GS009

## 🏦 银行/证券/金融开户场景

**原则 B01 — 必须说明具体机构名称**
银行/证券开户类申请，申请事由必须包含：①具体机构名称（哪家银行/证券公司），②目的（投资/理财/合规/资金管理）。仅说"要办开户"不够。
- 佐证：GS005（什么证券公司？）、GS006（中信证券，但未说目的）

**原则 B02 — 必须说明为什么必须单独开户**
若涉及单独开设账户：须说明为什么不能用现有账户，即开新户的必要性。
- 佐证：GS005（为什么要单独开一个银行账户？）

**原则 B03 — 法人意愿视频内容须与申请目的完全一致**
法人意愿视频的内容必须与实际申请目的一致。若视频说"开立对公数字人民币钱包"但申请事由是"开普通对公账户"，属于目的不一致，需追问。
- 佐证：GS005

**原则 B04 — ICBC 单位外汇交易申请书：法人章由银行规程背书，OCR 低置信不阻碍结论**
工行对公外汇汇款使用"单位外汇交易申请书"，该表单须加盖法定代表人章为银行操作规程强制要求。当申请人已提供外汇汇款必要性的客观证据（外部发票、对账单等），且操作场景为 ICBC 外汇汇款时：
- 印章类型（法人章）由银行规程背书，无需申请人额外证明，不追问替代方案
- 申请书截图 OCR 低置信（表单字段模糊）不阻碍结论，低置信仅参考
- 结论可给通过，评论中可标注截图质量供参考
- 佐证：2026-06-26 #1（刘静依，越南仓储 Fastock 外汇汇款）

**原则 B04' — 金融/政务机构标准业务：机构规程背书，证据形式不限官方界面（2026-07-26 王爷定，泛化 B04）**
当【资质流向方(dest) = 银行/证券/基金/保险/政府机关/税务/工商/社保/公积金等金融或政务机构】且【业务属该机构的标准规程操作】（开户/销户·注销·U盾·网银/账户变更/外汇/办证/账户维护等）时：
- 该操作强制要求的印章（法人章/法定代表人章）、原件（营业执照/身份证）由**机构规程背书**——机构要求本身即依据，无需申请人额外自证"证据充分"；
- 证据只看"机构是否确有此要求"，其**形式不限官方界面截图**——客户经理微信/短信告知、机构资料清单、官方通知、办事指南等客观来源均可，**不因"IM转述/非官方界面"就判需补充**；
- 豁免：不追问替代方案、不套 R02（双章合同）/R07（转授权）——这是配合机构强制要求、非商业授权；
- 仍须确认：流向方确为该机构、业务确为标准规程操作、事由说明了"做什么+为什么"（P03 操作原因仍适用，防"只要材料不说原因"）；
- 🔴 **边界**：仅限"配合机构强制要求"的标准业务。若把法人资质**授权给商业第三方（普通公司）**使用，仍走高风险的授权/双章路径（C0x/R02/R07），**不适用本条**。
- 佐证：2026-07-25 #67（凡岛投资，工行 U盾注销，工行经理微信告知资料清单）

## 🌐 平台场景（举证/入驻/账号操作）

**原则 P01 — 平台举证：附件背景充分时申请事由可短**
消费者纠纷→平台要求商家出具商标注册证举证品牌权属，属于"平台举证"场景。
- 申请事由不需要很长，结合附件截图（买家纠纷截图+平台要求截图）整体判断。
- 短申请事由（如"天猫平台举证使用"11字）+充分背景附件=可通过。
- 注意：商标注册号字段须填写（R01）。
- 佐证：GS010

**原则 P02 — 官方/政府/平台强制要求：不追问替代方案**
平台/官方/政府对我司提交资质有强制规定的，不需要问可不可以用其他替代，因为是强制要求的，不用审核是否有替代方案。
- 触发标准（重要）：P02 须「被证明」而非「被说明」。必须有客观证据——平台/官方界面含要求文字的截图或官方文书。纯申请事由自述（「平台要求提供XXX」）不得触发 P02 豁免，无截图时按正常证据链核实处理。
- 佐证：GS001（仲裁），GS002（法院），GS003（企标网）

**原则 P03 — 平台账号操作：必须说明为什么操作及影响**
平台账号操作类申请（账号回退/注销/转移），申请事由必须包含：
1. 为什么要做这个操作（背景原因）
2. 操作后的影响和必要性（为什么不能不做）
仅描述"操作需要什么材料"不等于说明了为什么要做。
- 如有平台要求提交特定文件（如账号回退承诺函），审批中必须包含该文件。
- 佐证：GS007（抖音账号回退）

**P02 与 P03 的适用边界：两者不冲突，同时检查**
- **P02 的范围**：为什么要提交"这种形式的材料"（手持身份证/原件/特定格式）→ 平台强制要求，不追问材料替代方案（对应**主体必要性**维度）
- **P03 的范围**：为什么要做"这个账号操作"（回退/注销/转移）→ 必须说明操作的触发条件和影响（对应**业务必要性**维度）
- 常见错误：看到平台要求材料（P02满足）就认为整体通过，忽略了操作本身原因未说明（P03未满足）。
- 正确判断：两者分别检查，互不替代。P02通过 ≠ P03通过。
- 佐证：GS007（抖音账号回退），历史案例：墨雪养发甄选蓝V回退（0CF88024）

## 🤝 合作/授权场景

**原则 C01 — 新合作授权书：证据链核实不可省**
新合作申请商标授权书/品牌授权书，同时提供以下两项时可直接通过：
1. 双章合同（R02）——证明合作关系存在
2. 对方要求出具截图（R11）——证明对方有要求

**缺少任一项时，须参见 analysis-protocol.md 阶段三「证据链层级」进行具体分析**，不能因为「业务必要性分析正确」就跳过证据链核实（必要性正确 ≠ 证据充分）。
- 佐证：GS011（达人投流，AI对但流程错）

**原则 C02 — 续期合作：合同有效期是核心判断点**
续期申请适用与新合作相同的 ①② 框架（见 analysis-protocol.md 证据链表）：
- ① 有效续期合同 + ② 截图 → 直接通过
- ① 有效续期合同，无截图 → 需补充截图（证明此次提交资质的必要性）
- 合同已过期 + ② 截图 → 通过（截图弥补无新合同，见证据链「往期合同+截图」行）
- 合同已过期且无截图 → 需补充截图

须核实合同有效期是否覆盖申请时点（年月日）；原合同过期 = 无新有效合同。
- 佐证：GS012（昆仑好客续期，合同已过期2025年12月31日，无截图 → 需补充）

**原则 C03 — 三方授权链条须确认完整**
当实际供货方/运营方与品牌方不是同一主体时（A 给 B 授权，但实际履行方是 C），须确认授权链条完整合法（A→B, A→C 或 B→C 的授权关系）。
- 佐证：GS012（慕可生物→大庆深连艺，但实际供货方为天美韵）

**原则 C04 — 线下渠道部门·品牌授权书·内部「特殊事项申请·提前开授权书」审批已通过 → 替代双章合同+截图（硬规则，2026-07-09 落成；2026-07-17 王爷收窄作用域）**
⚠️ **辨型第一**：本条**只治【线下渠道部门申请品牌授权书】**这一个场景。**其他任何场景一律不得援引 C04 替代双章合同**——对外商标授权（乙方是外部主体）、平台入驻/账号开通、新合作、内部商标授权书（走 C05）均不适用。援引前先确认：申请部门=线下渠道部门 且 资质=品牌授权书。
【线下渠道部门申请品牌授权书】尚无双章合同（R02）和/或对方要求截图（R11），但随附**内部「特殊事项申请」/「提前开授权书」类审批**且**状态=【已通过】**时，该已通过的内部审批即构成等效证据——证明公司已内部决策同意"先出授权书、合同后补"，**可代替 R02 双章合同 + R11 截图**闭合证据链层级，据此可判通过。
- 成立三条件（缺一不可，全部须核实、非申请人自述）：
  1. 随附件确为内部「特殊事项申请/提前开授权书」审批（不是普通说明/聊天截图）；
  2. 该审批状态经核实=**已通过**（"审批中/驳回"不成立，只回需补充/退回）；
  3. 授权范围与授权期限明确，且授权书与后续正式合同"同生同灭"（合同解除即授权失效）——**转授权红线（R07）仍照查**，不豁免。
- 边界：本条只替代"合作关系存在（R02）+ 对方有要求（R11）"两项证据，不豁免转授权/授权范围-期限/凭证造假等阶段三红线。
- 佐证：2026-07-08 #35 热夏提·古尔班江（凡岛/慕可与河南米伽化妆品合作，无双章合同，内部「提前开授权书」特殊审批已通过 → 通过）。

**原则 C06 — 线下渠道部门·品牌授权书：免 R11 对方要求截图（2026-07-17 王爷定）**
⚠️ **辨型第一**：本条只治**线下渠道部门申请的品牌授权书**。其他场景（对外商标授权/平台/账号/法人资质对外/新合作）一律不适用。
线下渠道部门申请品牌授权书时，**不要求提供〔对方要求证据截图〕(R11)**——该场景在实务上根本不存在「对方发一张截图来要授权书」：代理商是拿着授权书去 KA 门店上架，没有哪个门店会发截图向我方索要授权书。**强求截图 = 逼申请人去造一份证据**，反而降低证据质量。
- 成立条件：有〔双章合同〕**或**〔C04 内部「特殊事项申请/提前开授权书」特批已通过〕即可通过。
- 边界：仅免 R11 截图这一项。双章合同/内部特批、授权范围与期限、转授权红线（R07）、三方授权链（C03）**照查不误**。
- 佐证：2026-07-17 #54 邓淑贤（慕可→青岛朵妍，KONO 线下品牌授权书，125 家 KA 门店；有 16 页骑缝双章《KA代理商合同》+ 内部双章用印审批 + 新客户开拓审批，无对方要求截图 → 王爷判定维持通过）。

**原则 C05 — 内部商标授权书：三点硬核（甲乙方都是我司主体 + 信用代码 + 授权商标归属甲方）（代码化 R15，2026-07-09）**
⚠️ **辨型第一**：本条只治**内部商标授权书**（我司一个主体把某注册商标授权给另一我司主体/内部使用，甲乙方都是我司主体）。**不是品牌授权书**——品牌授权书是对外的、走 C01-C04；对外商标授权（乙方是外部主体）也不走本条，按对外授权核。
三点核查（`lib/trademark-auth-check.js` 已代码化为 R15，全程 fail-open）：
1. **甲乙方主体**：授权方(甲方=`公司主体`)、被授权方(乙方=`资质流向方全称…`)是否**都是我司主体**（清单=`common/entities.json` internal_entities + overseas_entities，含别名/USCC；registry 里的注册主体名兜底）。任一未匹配到我司主体 → 💧提醒人工确认是否为内部授权。
2. **社会信用代码正确**：主体 ↔ 统一社会信用代码一致。权威源=`entities.json` 的 name→uscc（境外用 tax_id/reg_no）。有则暴露供核对；缺则 💧提醒人工核（不臆造）。
3. **授权商标归属甲方（核心，治「把凡岛商标当慕可的」）**：授权书里的商标注册号，其**实际注册主体必须 = 甲方**。从 `trademark-registry-full.json` 建「注册号→归属entity」反查索引：
   - 命中 entity ≠ 甲方 → **硬告警 MAJOR/SUPPLEMENT**：「授权商标 <号> 实际注册在【<owner>】名下，与授权书甲方【<甲方>】不符，请核实归属」；
   - 命中且 = 甲方 → 通过；
   - 注册号不在库 → 💧提醒人工核（fail-open，别因库不全误判不符）。
- 典型错误（本条要治的）：**凡岛商标 ≠ 慕可商标**——甲方写慕可，却把实际注册在广州凡岛名下的商标(如 WIS 系 56896430)当慕可的商标授权，属归属错配，必须挡下核实。
- 表单/视觉边界：甲乙方/注册号若只在授权书**图片正文**里(needs_vision)，代码侧拿不到 → 降级 💧提醒，不臆断不符。校验以表单能拿到的结构化字段为准。
- 佐证：（待补——首个真实内部商标授权书归属错配件命中后回填）。

## 🏅 内部用印/荣誉场景

**原则 I01 — 内部荣誉证书/内部文书用章：主体一致+事由自洽+无外部流向+风险极低 → 直接通过（硬规则，2026-07-09）**
法人章/法定代表人章用于**公司内部**荣誉证书、内部表彰、内部文书等，且同时满足下列四条时，与"内部授权"同理，可**直接判通过**，无需外部证据链/对方截图/合同：
1. **主体一致**：用印主体 = 申请公司主体（法人章归属该公司）；
2. **事由自洽**：申请事由确为内部用途（荣誉证书/内部表彰/内部制度文书等），逻辑自洽；
3. **无外部流向**：资质/文书不流出公司、不对外部主体承担法律责任、不作对外背书；
4. **风险极低**：用印结果仅在公司内部生效，无对外或法律敞口。
- 🔴 边界（务必先判）：若荣誉证书/文书**对外**（发给外部合作方、用于对外宣传背书、作为对外资质凭证），则**不适用本条**，按正常"看流向/看用途/业务必要性/主体必要性"完整审。判定"无外部流向"前须从事由+附件确认流向确在公司内部。
- 佐证：2026-07-08 #36 林世武（广州凡岛网络 26 年 Q2 内部荣誉证书用章，主体一致、无外部流向 → 通过）。

## 🆕 新项目/新业务场景

**原则 N01 — 签署外部合同需内部决策文档**
新项目/新业务签署外部合同（如通信服务合同、SaaS 合同），除合同本身外，需提供内部决策文档（价值分析、必要性分析、风险分析、需求方分析）。
- 区别于常规合作续期（续期不需要决策文档）。
- 佐证：GS008（移动400 AI外呼项目）

**原则 N02 — 法人签名 vs 法人章须说明原因**
申请法人签名（而非法人章）时，需说明为什么合同中必须用签名（而非章），即法律或业务要求。
- 佐证：GS008（"为什么一定要法人签而非法人章？"）
