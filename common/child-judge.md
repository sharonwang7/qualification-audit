# 子代理判断规格（child-judge）· 资质审核

> 这是【子代理专读】的紧凑判断规格。你（子代理）只审【1 条】资质申请。**不要读整份 SKILL.md**（那是父 agent 的编排规格，你用不到、读它会耗光你的 10min 预算）。本文件够你判 95% 的情形；只有下面明确标"深读"处才去读大文件。

## 🔒 棘轮阶段锁（Ratchet-locked Phases）

子代理审核分三个不可逆阶段。每阶段完成后，落盘结果视同「棘轮齿槽锁死」——后续阶段不得修改前阶段的输出。

> 🎯 **规则按需注入（scoped_rules）**：`case` 返回会带一个 `scoped_rules` 字段，它根据该案的资质类型、流向方、事由自动匹配了适用场景和规则子集。**子代理优先读 scoped_rules**——active_rules 是你必须关注的规则，excluded_rules 是明确不适用于本案的规则。这帮助你节省上下文、避免套错规则。如果 `scoped_rules` 为 null（未匹配到场景），则回退读下方全量判据。

| 阶段 | 触发器 | 落盘 | 锁定范围 |
|------|--------|------|---------|
| **Phase 1 [LOCKED]** | `case` 返回 | `case_file` / `fando-ocr-cache` | 场景类型、红线结果、附件状态（不可再辩"没看清"） |
| **Phase 2 [LOCKED]** | `write-result` 返回 ok:true | `result_<code>.json` | verdict、fullAnalysis、applicantAction（不可再改判） |
| **Phase 3** | `fair` 执行 | `pending_actions CLOSED` | 仅 FAIR 执行；操作失败 ≠ 改判，只能重跑 fair 或 R 修订 |

- Phase 1 锁定后：子代理**不得**在后续步骤中要求重新 `case` 或重新下载附件——"我忘了看"是时间管理问题，不是重跑理由。
- Phase 2 锁定后：子代理**不得**自行修改已落盘的 result.json。如果撤回→必须走 `R#N 修订`（生成新记录，旧记录留在 `revisions.jsonl` 永久可查）。
- Phase 2→3 的间隙：必须 gen-card 发卡→用户看到→用户确认 F/A/I/R——这个间隙由 `card_was_generated` 守卫保障。子代理**不得**跳过 gen-card 直接上 fair。父 agent 在 write-result 后必须 gen-card、不得在卡片未生成时执行 fair。

## 🔴 最高铁律：落盘是【强制终点】，不是可选
子代理最容易犯的错：做完分析、说了一句结论就以为完事了——**错。分析了但没 write-result 落盘 = 这条等于没做**。所以：
- **先把时间留给"分析完 → 立刻写文件 → 立刻 write-result 到 ok:true"这三步**，宁可分析粗一点，也必须先落盘成功再回话。
- 顺序【不可颠倒】：① 用 `write` 写 `result_<instance_code>.json`（唯一名，别用共享 `result.json`）→ ② 跑 `write-result <instance_code> <该文件的绝对完整路径>` 🔴【路径坑】你的 `write` 常写进 workspace，而 write-result 默认在 skill 目录找→找不到；**第二参必须传绝对路径**，别传相对 `result_<code>.json` → ③ 被打回就【改完重跑直到 ok:true】→ ④ 【才】回一句话。
- `verdict` 只能是纯中文 `通过/需补充/退回/转人工`（工具会自动剥 emoji/空白兜底，但你别主动加 emoji）。
- 回话【必须带落盘状态】：`[write-result:ok] Case <申请人>: ✅通过/⚠️需补充/❌退回/🔴转人工（资质类型，一句话理由）`。跳过件回 `[skip] ...`。没落盘成功就【别回 Case 行】，直接告诉父 agent 你卡在哪。

## 执行顺序（Phase-locked）
1. 跑 `node scripts/audit-tool.cjs case <instance_code>` 取数据 → **Phase 1 LOCKED**（场景、红线、附件定型）
2. `in_scope=false`/`should_skip=true` → 先跑 `node scripts/audit-tool.cjs batch-skip <instance_code>` 登记，再回 `[skip] ...`。**绝不 write-result 产出审核结果**（越界/无管辖资质件归此；无从三阶段就 skip，绝不填占位符空壳，工具层也会硬拒）。
3. `fast_track.flag=true` → 已预填通过，回 `[write-result:ok] done(通过)`。
4. 否则做完整三阶段判断（下方），构造 result → 落盘（见最高铁律）→ 回话 → **Phase 2 LOCKED**（verdict + fullAnalysis 不可再改判）
5. 父 agent gen-card → 用户看到卡 → 用户 F/A/I/R → **Phase 3**

## 步骤 0：资质分类 + 场景
**0a 资质分类**（判是否属总经办管辖）：
| 类型 | 关键词 | 行为 |
|---|---|---|
| 法人资质 | 法定代表人章/签名/身份证、法人章/签名/身份证 | 深度审核 |
| 董事 | 董事签字/签名/身份证/信息 | 深度审核 |
| 品牌授权书/商标注册证/商标授权书 | 同名 | 深度审核 |
| 🚫 其余印章 | 公章/发货专用章/财务专用章/合同章等【印章刻制·用印】但非法人章/法定代表人章 | **越界**（归行政/内控）→ skip |
| 其他/其它 | 均不匹配 | ①事由扫词→②附件扫资质类型→③皆无则 skip |

> **印章归属边界（王爷定界）**：总经办【只管「法人章/法定代表人章」】。其余一切印章刻制/用印（公章、发货专用章、财务专用章、合同章…）属行政/内控，**非我方管辖 → 越界 skip**。切勿因"印章类"就顺口纳入（曾出"公章我们审"事故）。
> **勾选项与实质不一致时看实质**：申请人勾的「申请资质」只是入口，事由/附件里实际要对外提供的资质才是审核对象。勾了「行政公章」但事由写「合作方要求提供商标注册证」→ 商标注册证是管辖资质，按合作/授权类正常审并给结论，公章部分在结论里注明转行政（GS017）。反过来，勾「其它」且事由/附件都扫不到管辖资质词根 → 越界 skip（GS023）。

**0b 场景 + 关键判据【已内联·判断用这个就够，不要再去读 scene-principles.md】**：
识别场景后直接用下面对应判据判。场景可叠加、可命中多条。只有下面明确写「见 analysis-protocol」的证据链层级细则、或极罕见疑难，才去深读大文件；**正常判断中不要读 scene-principles.md / analysis-protocol.md（会耗光你的时间预算）**。

- **诉讼/仲裁**（流向方含法院/仲裁/公证，或流向方填成了对方当事人/自然人/代办人但事由、使用平台指向法院/仲裁委——按字段填法否定场景是错的，GS001）：先分 A/B（D1）。**A 凡岛自诉**（无律所/代理/维权机构介入）：法律强制 → 【豁免】阶段二必要性(Q1/Q2)+主体必要性+阶段三替代控制+R02双章/R07转授权/R11截图/R05（结论注「L01豁免·A自诉」），只确认流向=法院/仲裁委、有对应文书附件（起诉状/仲裁申请书含对方当事人提交的照片/受理应诉开庭通知，任一即可；劳动仲裁里员工的仲裁申请书就是被诉证明，不要再要受理通知，GS001）。**B 委托外部**（安盾/务新/律所/代理机构拿凡岛资质去办案）：①委托/维权服务合同【双章】每次必查，缺→需补充；②转授权禁止；③期限【分类型】——商标侵权/假货/仿品类维权诉讼**免查期限**（维权合同约定期限内受理的案件办至结案，到期不影响，2026-09-13 王爷定），其他诉讼/仲裁委托仍查授权期限在合同期内；④B 路径不要求对方要求截图(R11)和立案通知，双章合同+起诉状/仲裁文书即成证据链。商标侵权诉讼(L03)：有侵权事实+注册号已填(R01不触发)+起诉意图明确 → 通过。⚠️事由里出现的平台名 ≠ 流向方（流向是法院，L02）。
- **银行/证券/金融**（事由含开户/账户/银行/证券/基金/理财）：①须写明机构名+目的(投资/理财/合规)，仅说"要开户"不够(B01)；②单独开户须说明为何不能用现有账户(B02)；③法人意愿视频内容须与申请目的一致(B03)；④工行外汇「单位外汇交易申请书」法人章=银行规程强制、其 OCR 低置信不阻结论(B04)；⑤**【金融/政务机构标准业务·B04'，2026-07-26 王爷定，2026-09-13 明确边界】**：流向方=银行/证券/基金/保险/政府机关/税务/工商/社保等机构 且 业务=该机构标准规程操作(开户/**注销·销户/网银U盾**/变更/外汇/办证)时，分两段判——
  **【B04' 免掉的】**（这几项不要再问）：① 替代方案（机构强制要求，不问能否不提供）；② R02 双章合同、R07 转授权、R11 官方界面截图；③ 材料清单的证据形式——客户经理微信/短信告知、机构资料清单、官方通知均可，**勿因"IM转述/非官方界面"判需补充**；④ 机构要哪些材料以机构规程为准，不质疑机构清单本身。
  **【B04' 不免的】**（缺一仍判需补充）：① **Q1 业务事件**——这笔业务为什么发生，必须由申请人答实，机构要求不能替代它。🟢 **Q1 答到什么程度算答实（2026-09-14 按王爷历史批件校准）**：常规规程（工商变更/年检/配合监管调查/提升额度/开户）说清「办什么、为了什么」即可，例如「提升一般户额度，用于买入腾讯股票」已答实——**不追问投资决策本身合不合理、不要求股东会决议或内部立项文件**（审核边界，GS016b）；只有**异常情形**才追问起因：账号遗失/找回（为什么会丢）、已有账户却要单独新开（为什么现有的不能用）、事由与材料自相矛盾。②' **银行/政务标准业务的证据形式**：公司致机构的公函、机构表格/回执、政务系统待办界面截图，本身就证明业务在该机构办理，**不再要求机构另出一份「请提供身份证/营业执照」的告知**，材料清单由规程决定（王爷已批：工行额度变更凭单位公函通过、一网通变更凭待签名界面通过、市监所配合调查凭对接群材料清单通过）。反例：「凡投要在工行单独开户」须说明什么证券号、为什么不能用现有账户、视频里为何要提「对公数字人民币钱包」（GS005）；「商标局账号要重新注册」须说明账号为什么会遗漏（GS015a→补了原因即通过 GS015b）；「参与广发资管单一资产管理计划」须说明这个计划是什么、凡投为什么参与（GS016a→补了 QDII 说明即通过 GS016b）；② Q2 不做会怎样（机构强制通常可直接成立，一句话即可）；③ 流向方确为该机构、业务确为该机构标准规程（P03）。
  🟢 **投资类业务同样走这条（2026-09-14 王爷定）**：凡岛投资等内部主体向基金管理人/券商/资管机构办基金认购、出资承诺、合伙协议签署或修订、券商交易系统或算法服务开通——管理人/券商的材料清单即依据，免替代方案、免双章合同、免内部立项/决策文件，不质疑投资决策本身；只要事由说清是什么产品/项目、做什么（「君联基金认购，通过君联间接投资 DS 项目」已答实；只写「基金认购」不知哪只基金则需补充）。
  🔴边界：仅"配合机构强制要求"；把法人资质**授权给商业第三方(普通公司)不适用、仍走授权/双章(C0x/R02/R07)**。**代办机构替公司办政务规程（注销/变更）也算商业第三方**：政务规程本身免替代方案和期限，但必须有与代办方的双章服务合同或已通过的内部审批链接（2026-09-14 王爷定：代办也要合同）。
- **平台举证/入驻/账号**（流向方是平台名，或事由含举证/入驻/回退/注销/转移）：①平台举证=短事由+充分背景截图(买家纠纷+平台要求截图)可通过、注册号须填(P01)——「平台要求」的门槛：买家质疑品牌资质/申请退款 + 平台客服已介入或催促，即构成举证需求，**不必再有平台单独的「请提供注册证」通知**，这是自家店铺向平台自证权属、不是对外合作，不追问必要性（GS010）；②平台强制豁免替代方案须【被证明非被说明】——要有平台界面/官方文书截图，纯自述"平台要求"不豁免(P02)；③账号操作(回退/注销/转移/**找回/重新注册/解绑**，含商标局、税务等政务平台账号)事由须含【为什么做+操作影响】，只说"要什么材料"不算；**「为什么做」必须答到起因这一层**——账号为什么会遗失/为什么要换绑/为什么现在要做，复述「要找回」「要重新注册」不算答（GS015a：「交接时遗漏了账号」没说为何遗漏→需补充；GS015b 补了「合规中心遗失账号密码、人员流动无人知晓」→通过）(P03)；④P02(材料形式)与P03(操作原因)分别查、互不替代——官方界面截图证明「平台要这些」，不证明「我们为什么走到这一步」。
- **合作/授权类**（资质含"授权书"或有合作合同附件）：①新合作授权书=双章合同(R02)+对方要求截图(R11)两项齐 → 通过；缺任一 → 过阶段三「证据链层级」(见 analysis-protocol)，别因"必要性对"就跳证据(C01)；②续期看合同有效期是否覆盖申请时点：有效合同+截图→通过、合同过期+截图→通过(截图弥补)、过期且无截图→需补充(C02)；③供货方/运营方≠品牌方时须确认三方授权链完整(C03)；④**【仅限线下渠道部门申请品牌授权书】**尚未盖双章合同时，随附内部「特殊事项申请/提前开授权书」审批且状态【已通过】→ 可替代 R02 双章合同 + R11 截图（转授权 R07 仍查）。**其他任何场景（对外商标授权/平台/账号/新合作等）一律不得援引 C04 替代双章合同**(C04，2026-07-17 王爷收窄作用域)；⑤**【线下渠道部门·品牌授权书】免 R11 对方要求截图**——该场景实务上不存在「对方发截图来要授权书」（代理商拿授权书去 KA 门店上架，没人会发截图要它；强求截图=逼申请人造证据）：有〔双章合同〕或〔C04 内部特批〕即可通过(C06，2026-07-17 王爷定)。
- 🔴 **【法人资质对外·证据门槛｜2026-07-17 王爷定】**：法定代表人身份证/法人章/法定代表人章/法人签名等**【法人资质】**（词根=法人/法定代表人/董事/股东，与 R05 `applies_to` 同源；⚠️**营业执照属【行政】、非总经办管辖，不适用本条，勿再纳入**）**对外提供给外部主体**时——
  ① **纯平台标准入驻/开店**（天猫/抖音/京东开店等，无特定合作对手、纯入驻）：〔平台官方后台/规则页截图〕即可通过（须【被证明非被说明】，见 P02）。
  ② **涉及合作**（事由或材料出现「合作/经销/代理/联营/合作业务」等，与特定外部主体建立业务关系）**或属本表未覆盖的新情况**（事由/资质在 0b 各场景触发词里都找不到对应者，如「月结/开通」）：须**同时**具备〔双章合同/协议 **或** 内部用印/立项/合作审批链接（状态已通过）〕**＋**〔对方要求证据截图〕，**缺任一 → 需补充**。
  ③ **判①还是②：事由里出现「合作」字样即按 ② 走**，不因对方是知名平台而降档。（#50 京东月结即此：事由含「合作京东快递业务」→ 走 ②；仅一张对接人截图、无合同也无审批链接 → 需补充。）
  ④ 🔴 **对接人私聊/IM 群聊转述截图 ≠ 平台官方界面截图**：人转述「要准备什么资料」属【被说明】。它可充当 ② 里的〔对方要求证据截图〕，但**绝不可**充当 ① 的官方证据，也**绝不可**替代合同/审批链接。
- **内部商标授权书**（"商标授权书"且甲乙方都是我司主体）：甲乙方都我司主体+信用代码一致+授权商标注册号实际归属=甲方（R15 已代码化、fail-open）；⚠️凡岛商标≠慕可商标，别把注册在凡岛名下的商标当慕可授权(C05)。
- **新项目/新业务**（事由含新项目/外呼/SaaS/系统/签署合同 且非续期）：①签外部合同须附内部决策文档(价值/必要性/风险/需求分析)，续期不需要(N01)；②法人签名(而非章)须说明为何必须签名(N02)。
- **内部用印/荣誉**（法人章用于内部荣誉/表彰/文书、无外部流向）：主体一致+事由自洽为内部用途+无外部流向+风险极低 → 直接通过，无需外部证据链；⚠️若对外(发外部/对外宣传背书)则不适用、按完整审(I01)。

⚠️ **旧版表单陷阱**：旧表单字段(拟用资质/相对方全称/使用平台)可能被工具误判 `in_scope=false`（GS008-012 都是旧表单、实际都在审核范围内）。**判 in_scope=false 前，若疑似旧版表单，仍按资质审核走三阶段、别直接 skip。**

## 附件铁律
- `status≠ok`（empty 认空/failed 读失败）→ **跳过该附件、基于可读信息判四维度**；"读不出字"≠"没问题"。可读信息够→结论照给+评论标注失败附件；不足某维度→⚠️需补充；全部失败且表单不足→🔴转人工。`low_conf` 仅参考。
- `status=needs_vision`（图片/扫描PDF渲染页）→ 用 `image()` 读其 `vision_paths`，识别内容当正文纳入三阶段。**needs_vision ≠ 失败，绝不可跳过**；视觉确实读不出才标 failed。`truncated_pages=true`（只渲了**部分页**，具体渲了哪几页见该附件 `content`；策略=前 N 页+末 M 页，签章区已含）→ fullAnalysis 里写清：已读到什么/关键条款可能在**未渲染页**/需人工核对原件那些页，禁止只写"期限不明"。`truncated_pages=false` = **全部页已渲染**，可据此下确定结论。
- `status=ok` 大附件按需 `read-attachment <code> <idx>` 取全文；评论里转成判断依据，别机械复述。
- 合同/授权书看 `seal_count`（红章粗检，≥2 约=双章、0 约=没盖）——**仅线索**，会漏蓝/黑/淡章、误检大红图；双章是否成立由你结合甲乙方/盖章字样判（R02）。
- `comments_summary` = 申请人评论区文字回复（补料说明、"决策文档见链接"、"双章在评论附件"常在此）→ 非空【必须逐条读并纳入判断】，**含嵌套 replies**；表单独立附件字段（项目决策文档、对方要求截图）也须逐一审到。🔴 **标了「已撤回」(is_delete) 的申请人评论及其附件照样读、照样采信**——申请人常误撤回或撤回重发，撤回≠不存在；只有内容自相矛盾时才注明以最新一条为准。**绝不能因为「已撤回」就说「不能采用」而判需补充**（GS016b 禁答点）。
- 🔴 **"核原件"前先判物料流向**：这份资质是①外部主体交来【验真】的，还是②公司自有、对外【提供】的？②的场景（法人签名/章、法定代表人身份证、营业执照、开户许可证等由总经办/行政签发、原件本在公司手里，申请人只是领取转交给平台/对方）——【根本不存在"申请人携原件当面核对"，绝不可要求核原件】；平台要求清单截图是"对方有要求"的证据、不是待验真原件。只有①场景且有真伪存疑信号（涂改/拼接/自相矛盾/关键条款在未渲染后续页）才提核原件。水印建议：凡法人资质（法人章/法定代表人章/签名/身份证）、营业执照等公司自有证件对外【提供】时，verdict=通过时必须在 fullAnalysis 阶段三·技术控制中给出水印建议（≤15字），格式：「建议在提供的文件上加盖水印「仅限XXX使用，复印无效，他用无效」」。此建议自动进审核记录供审批人参考，不阻塞流程。

## 步骤 4：三阶段判断（要点；完整规格【深读】 `analysis-protocol.md`）
🔴 **通过正门槛（缺省倒向需补充·举证责任在申请人）**：**"通过"仅当下面四条全绿**——
①【证据】有外部客观证据（被证明≠被说明；仅申请人自述、口头"已决策"、"证据链完整"感觉 → 不算证据）；
②【业务必要性】Q1+Q2 都答实：Q1=发生了什么业务事件才要这次申请（"什么事发生了"，不是"要什么材料"）；Q2=不做会怎样（法律/合同/平台强制？还是可不做？）；
③【主体必要性】为什么必须公司/法定代表人出面：法律强制(诉讼/仲裁/工商) or 合同指定法人签章 or 平台要求企业/法人认证——三者居一才成立；
④【无退回项】无凭证造假/伪造/二次仍无证据。
**任一条存疑或未证 → 判需补充（不是通过）**。别因"没看到明显问题"就通过；没证到满足=需补充。⚠️ 场景已覆盖必要性的(L01诉讼仲裁 / P02平台强制)按场景原则免重复审②。
- **阶段一·证据链核实**：见①。无证据→标"证据不足"、不直接驳回。合作/授权类另过证据链层级表（7 行，第 7 行退回在此定）。
- **阶段二·逻辑穿透**：把②③一次列全缺失项。🔴 **三格必须填实，任一格空/靠脑补 = 需补充**：[发生了什么业务事件]／[不做会怎样]／[为何必须法人出面]。无证据绝不脑补、标"无法从现有信息确认"。
- **阶段三·风险控制**：替代控制 + 限制控制（转授权条款→需补充修订版授权书；授权范围/期限不明→需补充；凭证造假→退回）+ 技术控制（≤15字水印建议）。
- deterministic 红线纳入；`ocr_gate.all_ok=false`/`needs_human=true` 时按附件铁律判。分析一致性：全程用同一套完整三阶段，禁简化版。
