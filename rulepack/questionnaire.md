# 采集问卷 M0–M8（工厂输入端）

> 任何审核场景，业务方对着这套问卷把资料交出来，AI 就能一键提炼成五件套。**填写约定**：拿不准写"待定"并标原因，别硬编；每条规则尽量给一个反例（什么情况算不通过）。
>
> **采集顺序**：M0 → M8(先摸已有资料，能填直接抄) → M1/M6(先划红线和边界，收敛范围) → M2(定分档口径) → M3/M4/M5(细化规则) → M7(补基准和案例)。

## 问卷 → 五件套的映射

| 模块 | 喂养 | 作用 |
|---|---|---|
| M0 场景画像 | 全局锚点 | 审什么、审到什么程度 |
| M1 硬红线 | ③红线 | 一票否决项 |
| M2 判定分档 | ⑤策略 | 四档 + 默认档 + 闸门/提醒 |
| M3 字段映射 | ①字段 | 表单字段 ↔ 审核要素 |
| M4 数据源算子 | ②规则 | A ⟨算子⟩ B → 档 |
| M5 参数/阈值 | ②规则+⑤策略 | 数字/口径参数化 |
| M6 边界 | ⑤策略+③红线 | 不管/只提醒 |
| M7 基准+题库 | ④知识 | 基准表 + golden |
| M8 已有资料 | 原料入口 | 现成文档/历史 case |

## M0 场景画像
- M0-1 审的是什么单据/申请？一句话定义。
- M0-2 谁提交、谁审、结果给谁用（下游）？→ 决定要不要"转人工"、结论严肃程度。
- M0-3 有哪些子类型？各占比？→ 规则分组第一刀。
- M0-4 量级多大？错判一次代价（钱/合规/返工）？→ 决定默认档偏松/偏严。
- M0-5 目前纯人工还是半自动？痛点最集中在哪？

## M1 硬红线（一票否决）
- M1-1 哪些情况命中就必须驳回/拦截，不看其他证据？
- M1-2 每条红线判定依据？可机器判定吗？（不可机判的红线落"转人工"）
- M1-3 命中后动作？（直接驳回 / 拦截转人工 / 记录阻断）
- M1-4 有没有"看似红线其实只是预警"的情况？举反例（防误杀）。

## M2 判定分档口径（四档 = 通过/预警/驳回/转人工，默认=疑则补·预警）
- M2-1 四档在本场景各代表什么？各给 1 例。
- M2-2 默认档确认：拿不准/证据不全默认"预警补件"对吗？有无例外必须直接驳回？
- M2-3 哪些是闸门(能改结论)？哪些只是提醒(不改结论)？逐条标。
- M2-4 "转人工"触发条件？（红线不可自动判/金额超阈/材料类型不支持/多次预警未解）
- M2-5 一单命中多档，最终档怎么取？（一般取最严：驳回>转人工>预警>通过）

## M3 字段与要素映射
- M3-1 表单业务填的字段有哪些？（名称/类型/是否必填）
- M3-2 每个字段对应审核里哪个要素？
- M3-3 哪些要素不在表单里，要从附件/OCR/外部系统提取？（提取型=识别错高发区）
- M3-4 有无一字段多义/多字段同义？举例（消歧）。

## M4 数据源与算子（规则 = A ⟨算子⟩ B → 档）
- M4-1 逐条列校验规则：比对两边 A、B 分别是什么数据源？
- M4-2 用什么算子比？（相等/包含/日期覆盖/数值≤阈值/存在性/一致性/OCR匹配）
- M4-3 结果落哪一档？各分支都要说。
- M4-4 依赖哪些附件/外部数据？缺了怎么办（预警补件还是转人工）？
- M4-5 有无"多条规则组合才成立"的复合判断？举例。

## M5 参数/阈值
- M5-1 规则里所有数字/比例/时间窗，列成参数（名称/当前值/含义）。
- M5-2 每个参数谁有权调、影响哪些规则？
- M5-3 有无容差/缓冲参数？（金额四舍五入、日期±N天、OCR置信度下限）
- M5-4 OCR：置信度低于多少走预警/转人工？

## M6 边界（不管 / 只提醒）
- M6-1 哪些事项明确不归本场景管？（防越权替别人判断）
- M6-2 哪些检查只提醒不拦截？举 2 个。
- M6-3 有无"AI 只能建议、最终必须人定"的判断？（商业合理性/主观必要性）
- M6-4 反例：给一个"看着该拦其实不该拦"的真实 case。

## M7 基准数据与题库
- M7-1 判定需要哪些基准清单/字典？（主体清单/科目映射/白名单）在哪、谁维护、多久更新？
- M7-2 有映射类规则吗？（如"部门×店铺×关键词→科目"）给映射表结构。
- M7-3 **能给 8–15 个 golden 案例吗？** 每个含 输入+正确结论+命中哪条规则+为什么。覆盖四档 + 边界 + 历史误判。
- M7-4 历史被投诉/翻案的 case？错在哪？（翻案 case 最高价值，暴露盲区）

## M8 已有资料盘点（原料入口，能抄直接抄）
- M8-1 现有制度/SOP/培训/checklist 在哪？给链接。
- M8-2 现成表格/字典/清单有哪些？
- M8-3 有无历史审核记录（含结论和理由）可导出？（可反推规则和参数，也是 golden 来源）
- M8-4 哪些是最新权威？哪些已过期别用？（防喂 stale 副本）

## 自检清单（采齐了没）
- 覆盖度：每个子类型有规则或明确"同主流程"；五件套每件有内容且可追溯；每条规则分支齐全；依赖数据的规则写明缺料档。
- 口径：四档+默认档写死；每条检查标了闸门/提醒；红线标了"可机判+命中动作"且无误列；转人工触发器全、合并规则定。
- 参数：所有数字/时间窗/比例参数化且有 owner；容差、OCR 置信度下限已设值。
- 边界："不该管"清单非空合理；"只提醒"项固化；AI 不该独断的落到转人工/提醒。
- 题库：golden ≥ 8 覆盖四档+边界+至少 1 个翻案 case；用 golden 回归结论全对得上(对不上已记录并修规则,未改案例)。
- 资料卫生：基准清单是最新权威版；所有 [待业务确认] 列成追问清单未被猜测填充。
